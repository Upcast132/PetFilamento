# Modelos 3D (diseño propio)

Aquí van los modelos originales de las piezas impresas, diseñados por el
equipo. El reglamento de la feria (Art. 2.1) exige entregar los archivos de
modelado originales (STL y CAD) junto con el informe.

> **Pendiente:** subir los archivos.

## Organización

```
cad/
├── stl/      # piezas listas para imprimir (.stl)
└── fuente/   # archivos editables del programa de diseño
```
